## Требования

- Python 3.10+
- Google Chrome (для Selenium)
- [Ollama](https://ollama.ai) (опционально, для AI-распознавания запросов)

---

## Установка

### 1. Клонировать / распаковать проект

```bash
cd ai_curator_assistant
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. (Опционально) Установить Ollama + модель

```bash
# Скачайте Ollama с https://ollama.ai
# Затем выполните:
ollama pull llama3
```

> Если Ollama не установлена — ассистент работает через встроенный парсер на правилах.

### 4. Запустить приложение

```bash
python main.py
```

Откройте браузер: **http://localhost:5000**

---

## Первоначальная настройка

1. Перейдите на страницу **Настройки** (http://localhost:5000/settings)
2. Заполните раздел **Образовательный портал** — логин и пароль куратора
3. Выберите способ рассылки: **MAX Мессенджер** или **Email**
4. Заполните соответствующие данные (токен MAX или SMTP)
5. Нажмите **Сохранить настройки**

## Использование

### Через чат (http://localhost:5000)

Напишите запрос или используйте быстрые кнопки:

| Запрос | Действие |
|--------|----------|
| «отчёт по должникам» | Должники за последний семестр |
| «должники за 6 семестр» | Должники за конкретный семестр |
| «полный отчёт за весь период» | Сводная ведомость |
| «индивидуальные отчёты для каждого» | Файл на каждого студента |
| «отчёт за 5 семестр» | Ведомость за семестр |
| «статистика» | Сводка по группе |
| «отправить отчёты» | Рассылка готовых отчётов |

### Автоматическая рассылка

Настройте расписание в разделе **Настройки → Автоматическое расписание**.

## Структура проекта

```
ai_curator_assistant/
├── main.py              # Flask-сервер, маршруты API
├── config.py            # Загрузка/сохранение настроек (settings.json)
├── logger.py            # Логирование в файл + консоль
├── scheduler.py         # Автоматическое расписание
├── requirements.txt
├── settings.json        # Создаётся автоматически при первом запуске
├── logs/                # Лог-файлы (автоматически)
├── reports/             # Сгенерированные отчёты (автоматически)
├── modules/
│   ├── scraper.py       # Selenium: авторизация и парсинг портала
│   ├── analytics.py     # Парсинг HTML, расчёт успеваемости
│   ├── reports.py       # Генерация xlsx и pdf
│   ├── sender.py        # Отправка через MAX API или SMTP
│   └── ai_agent.py      # LLM intent detection (Ollama)
└── templates/
    ├── index.html       # Чат-интерфейс
    ├── settings.html    # Страница настроек
    └── logs.html        # Просмотр логов
```

## Отчёты MAX API

Для использования MAX мессенджера:
1. Зарегистрируйте бота на https://business.max.ru
2. Получите токен в разделе «Чат-боты → Интеграция»
3. Узнайте свой User ID в MAX
4. Введите данные в настройках
